# Mr.Bee — интернет-магазин мёда

Учебный e-commerce проект на чистом JavaScript (ES-модули, без сборщика и
фреймворков) с бэкендом на Firebase.

## Возможности

- 🔐 **Аутентификация** — регистрация, вход, роли `user` / `admin`
- 🍯 **Каталог** — поиск по мере ввода, фильтры по сортам и особенностям, сортировка, пагинация
- ⭐ **Отзывы и рейтинги** в реальном времени
- 🛒 **Корзина и оформление заказа** — с транзакционным списанием остатка на складе
- 👤 **Личный кабинет** — история заказов и свои отзывы обновляются live
- 🛠 **Админ-панель** — CRUD товаров, управление заказами и пользователями, модерация отзывов, статистика
- 📱 **Адаптивная вёрстка** — от 320px до десктопа, шапка на мобильных через hamburger-меню

## Стек

HTML · CSS · JavaScript (ES-модули) · Firebase (Authentication + Firestore)
